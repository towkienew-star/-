TOWKIE MORPHS — Minecraft Java 1.21.4 / Fabric
================================================

ЧТО ДЕЛАЕТ МОД
- J открывает меню внутри игры.
- Клавишу можно поменять: Настройки -> Управление -> Назначение клавиш -> Towkie Morphs.
- Слева список игроков, которые сейчас онлайн (по табу сервера).
- Выбор игрока, настройка 7 параметров ползунками:
  Общий масштаб, Высота, Ширина, Голова, Туловище, Руки, Ноги.
- Сброс одного игрока, сохранение настроек между запусками игры.
- Локальный эффект: видишь только ТЫ, другие игроки ничего не увидят.
- Не меняет хитбоксы, урон, дальность удара или размеры игрока на сервере.

КАК ПОЛУЧИТЬ JAR
1) Нужна Java JDK 21 (именно JDK), доступ в интернет.
2) Windows: дважды нажать build.bat. Или: Gradle 8.13 -> gradle build.
3) После успешной сборки установочный файл находится здесь:
   build/libs/towkiemorphs-1.21.4-1.0.0.jar
4) Положи этот JAR в папку .minecraft/mods.
5) Установи Fabric Loader под Minecraft 1.21.4 и Fabric API для 1.21.4.
6) Запусти 1.21.4 с Fabric, зайди на сервер или в мир и нажми J.

ОПЦИЯ БЕЗ СБОРКИ НА СВОЁМ ПК
- Загрузить файлы проекта в собственный репозиторий GitHub.
- В Actions -> Build Fabric Mod -> Run workflow скачать артефакт.

ВАЖНО
Это полный исходный проект, а НЕ готовый скомпилированный JAR.
В этой среде отсутствует интернет-доступ к зависимостям Fabric и Gradle,
поэтому мы не можем честно подтвердить успешную сборку и работу в игре.
По этой причине не выдаём исходники за готовый к запуску мод.

Проверенные целевые версии конфигурации проекта:
  Minecraft 1.21.4, Yarn 1.21.4+build.8, Fabric Loader 0.16.14,
  Fabric API 0.119.2+1.21.4, Loom 1.10.1.

Настройки: .minecraft/config/towkiemorphs.properties
Разные серверы и UUID игроков хранятся отдельно.
